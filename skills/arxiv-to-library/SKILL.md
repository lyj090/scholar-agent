# arXiv → Library

Discover arXiv papers, import to Zotero, and prune or dedupe what no longer
earns its place.

## Flow

```bash
bash ~/scholar-agent/scripts/skills/skill-gate.sh arxiv-to-library
```

Run `RUN=` first. Read `READ=` only when the task needs discovery or write
detail; `--verbose` adds the import/publish/merge/rollback spec sections.
